NDOTONIC — HACKATHON FAQ
Based on Ndotonic.md and HACKATHON_PITCH.txt · live at ndotonic.com


**Explain how your project uses AI to impact the world, specifically in the category you have chosen.**

Ndotonic is an AI-native author platform. We use AI to lower the barriers that keep impactful stories from becoming published books—especially in languages and regions where funding, distribution, and editorial gates are high. Authors get patron campaigns, Gemini-powered editing in Ink Studio, AI-narrated audiobooks, and GLC Media radio/TV promotion in one workflow. AI elevates manuscripts and production; authors stay in control of what ships. Mission: uncover hidden potential and amplify unheard voices.


**Explain the underlying business model of your submission.**

One connected workflow: Pitch → Fund → Write → Publish → GLC Media → Monetize.

Revenue comes from:
- Patron book-funding campaigns (platform fee on pledged funds)
- Marketplace sales of digital editions, audiobooks, and print (platform fee on transactions; authors receive the majority via Stripe payouts)
- Integrated publishing and promotion that keeps authors on-platform instead of renting attention elsewhere

Authors fund and create on Ndotonic; readers and patrons pay on Ndotonic; GLC Media drives discovery and promotion for featured stories.


**How will you sustain business operations in the future?**

Year 1: grow author acquisition, campaign GMV, and validate the full pitch-to-paying-reader workflow. Year 2: scale GLC Media content plus audio and print. Year 3: expand into rights and adaptation. Near-term operations are funded by bootstrapping and platform fees on campaigns and marketplace sales, with lean Docker Compose infrastructure on a GCP VM. We refine the author journey in production before scaling marketing and hiring as revenue or investment allows.


**Which AI tools have you leveraged while working on this project?**

Production:
- Google Gemini API (google.generativeai) — Ink Studio editing, craft review, chat, cover generation, audiobook section suggestions, and related author workflows
- Google ADK — multi-agent GLC radio news pipelines (reporter, anchor, assembly)
- Google Cloud Text-to-Speech (Neural2) — audiobook narration and GLC broadcast narration

Development and operations:
- AI agents — custom Cursor cloud security-auditor (deploy diff review by severity) and remediation agent (applies fixes without manual triage)
- Render MCP — AI-assisted infrastructure and service checks during deploy and ops in Cursor

Infrastructure alongside AI: Icecast, Liquidsoap, Flask-SocketIO, PostgreSQL, Stripe.


**Explain how your business model shared above is sustainable and viable.**

The model ties revenue to outcomes authors already want: funded manuscripts, published books, and paying readers. Campaign and marketplace fees scale with author success without heavy upfront cost for creators. Owning promotion through GLC Media reduces dependence on paid social algorithms. A single platform replaces a dozen fragmented tools, improving retention. Lean GCP + Docker operations keep fixed costs manageable while the product is live and iterating with real users.


**Please explain how your business operates with AI.**

AI is embedded in daily author and broadcast workflows, not bolted on as generic chat.

Ink Studio: six editing modes (grammar, spelling, linguistic errors, plot continuity, pacing and tension, narrative style) plus cover generation and manuscript assistance via Gemini.

Audiobook studio: Cloud TTS narrates selected sections; Gemini helps suggest which sections to include.

Publishing: Gemini supports pre-publish elevation—craft review, covers, narration suggestions, and trust-related checks; authors review and approve listing terms before anything goes live.

GLC Media: ADK reporter agents research and draft scripts; an anchor agent coordinates the show; Cloud TTS narrates; assembly produces finished radio content. Live radio (Icecast) and live TV (HLS) distribute it on ndotonic.com.


**Please explain the extent to which AI is live in production and executes key decisions.**

AI is live in production at ndotonic.com across three layers:

Author-facing AI (human in the loop): Gemini powers Ink Studio editing, cover generation, audiobook section suggestions, and pre-publish craft checks. Cloud TTS narrates audiobooks and GLC broadcasts. ADK agents research, draft, and assemble GLC radio news. Authors still choose edits, accept listing terms, and trigger publish—AI elevates the manuscript; it does not list or sell books without author approval.

Automated production systems (no founder action): Stripe runs checkout, webhooks, platform-fee splits, and Connect payouts on every campaign pledge and marketplace sale—charges, fee calculation, and payout routing execute from verified webhook events, not manual steps. GLC news generation pipelines run end to end (reporter → anchor → TTS → assembly). GitHub Actions deploys to production on push to enhancements, with automatic rollback on failure.

Autonomous cloud agents (no founder action): A custom Cursor security-auditor agent on a cloud VM reviews each deploy diff by severity (Critical, High, Medium) before production ships. A remediation agent applies fixes from those findings in the pipeline. Render MCP (in Cursor) supports AI-assisted infra and service checks during deploy and ops. Together, these agents review and remediate code without me manually triaging every change—while author and payment guardrails above stay rule-based and consent-driven.


**Please explain which product from Google Cloud you used during the hackathon and how.**

- Compute Engine — hosts the production VM running Docker Compose (web app, PostgreSQL, nginx, GLC services, Icecast/Liquidsoap)
- VPC — private networking for services on the VM
- Cloud DNS — ndotonic.com domain resolution
- IAM — service accounts and policies so app and API services authenticate safely to Google APIs
- Cloud Text-to-Speech — Neural2 voices for audiobook studio and GLC broadcast narration

Gemini API and Google ADK run against Google AI services using API keys and service credentials configured on this GCP-hosted stack.


**If your project uses an LLM, it must use Gemini API for at least one LLM call. Please explain which LLMs are used in the project and specifically how the Gemini API is used.**

Yes. Gemini API is used in production via google.generativeai.

Gemini powers:
- Ink Studio copy editing, craft review, and author chat (e.g. gemini-2.0-flash and related models per feature)
- Book cover image generation (Gemini image models with Imagen fallback where configured)
- Audiobook section classification (which chapters/sections to narrate)
- GLC news topic validation and reporter/anchor agent text generation inside ADK pipelines
- Ink Studio developmental editor and brainstorming agents (ADK + Gemini)

Cloud Text-to-Speech is not an LLM; it handles speech synthesis. All generative text and image LLM calls for author and GLC workflows go through Gemini.
